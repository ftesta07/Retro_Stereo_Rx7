# PaltaTech template for KiCad project

In this repo you will find a template for KiCad project that contains:
- Cover sheet
- Root sheet
- Layout worksheet template
- Common netclass definitions
- Folder structure
- Board2pdf config file
- .gitignore file

## How to use it

1- Copy the content of the repo in user template folder for kicad 

  Windows: C:\Users\<username>\Documents\KiCad\9.0\template\
  
  Linux: ~/.local/share/kicad/9.0/template/
  
  exclude from the copy the this readme file.
  
2- Create new project from template

<img src="meta/template1.png" width="800">

3- Select PaltaTech template form User templates tab

<img src="meta/template2.png" width="800">

4- Name the project.

5- Use the files inside the pcb_design folder, delete the kicad_sch and kicad_pcb alocated in the root folder.
